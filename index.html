二、各阶段需求详情

阶段①：项目筛选与立项

核心痛点：并购标的筛选靠人脉和零散信息，缺乏系统化数据库；立项判断全凭经验。
功能点具体要求
并购标的数据库建立标的库，支持标签筛选（行业/规模/估值倍数/PE/技术壁垒/地域等）
主业匹配度自动评估内置集团及各所属公司主业范围库，读取项目行业领域后自动匹配评分
立项流程线上化所属公司/集团投资项目统一入口，根据项目类型（固投/股权）、计划内/外自动分流
计划联动立项时自动校验是否在年度投资计划内，计划外项目触发调整预警

阶段②：智能尽调平台 ⭐核心模块（四合一）

核心痛点：可研、商业、法律、财务四项尽调各自为战，数据重复采集，格式不统一，全靠人工交叉核验。

设计原则：四项尽调整合为一个平台，数据一次采集、多方复用，AI辅助分析自动生成各维度报告。

2.1 数据采集层（一次录入，四维共享）

采集项来源复用方向
项目基础信息立项阶段自动带入四维通用
可研报告/商业计划书所属公司上传AI提取→财务测算+商业分析
法律文件所属公司+律所法律尽调+合规检查
财务报表（近3年）所属公司上传财务尽调+估值测算
行业数据系统自动采集商业尽调+可研对标

2.2 AI分析引擎（5大引擎）

引擎功能输出
引擎一：可研完整性校验对标发改委标准大纲，逐项检查；逻辑校验缺失章节标红+逻辑矛盾提示
引擎二：主业匹配度分析项目行业与公司主业库关键词匹配匹配度评分（高/中/低）+偏离说明
引擎三：财务数据提取与测算自动识别PDF/Word/Excel中的财务数据自动测算IRR/NPV/回收期/盈亏平衡点/估值
引擎四：风险措施论证内置风险类型库，扫描风险章节完整性评分+缺失项+建议补充
引擎五：法律合规审查识别合同关键条款、诉讼风险、知识产权法律风险清单+合规建议

2.3 报告生成层

报告类型内容触发方式
《尽调综合分析报告》5大引擎分析结果汇总上传资料后自动生成
《可研对标分析表》系统测算vs企业自算，逐项对比引擎三自动输出
《风险清单与应对建议》按风险等级分类，含责任人引擎四+五联合输出
《估值参考报告》DCF/可比公司/可比交易多种估值引擎三扩展

阶段③：估值与交易决策

核心痛点：估值测算依赖Excel手工建模，不同方法结果需人工比对。
功能点具体要求
多方法估值自动测算DCF、可比公司法、可比交易法，输出估值区间
交易结构设计辅助模拟不同持股比例/支付方式对集团财务指标的影响
敏感性分析关键变量变动对IRR/NPV的敏感性自动测算
对赌条款模拟模拟不同对赌条件下的收益/风险场景

阶段④：审批流程自动化

核心痛点：审核路径靠人工判断，反馈轮次无管控，决策文件准备时间易延误。
功能点具体要求
智能路径判断根据项目类型、计划内/外、投资额自动匹配审核路径
分级审批流立项→可研→投资部→分管领导→集团决策会，各环节自动流转
反馈轮次管控每轮反馈自动记录，超5次自动锁止推送负责人
决策文件倒计时审核无误后锁定，决策前5天自动提醒
合规自动检查窗口期/持股比例/内幕知情人等合规事项自动检查
全流程留痕操作日志、审批单、法律意见自动归档

阶段⑤：投后管理与监控

核心痛点：投后数据散落各所属公司，风险发现滞后，经营指标缺乏持续跟踪。
功能点具体要求
投后项目台账所有在管项目统一台账，标注状态（正常/预警/重大变化/终止）
经营数据定期采集月度/季度自动推送所属公司填报经营数据
业绩承诺跟踪对赌/承诺指标自动跟踪，偏差超阈值自动预警
收益对标分析自动调取可研预测值与实际对比，偏差>20%标红
重大变化/终止流程分管领导→投资部→集团主要领导→自动更新状态→报送国资局
整改跟踪异常项目纳入"重点监控清单"，持续跟踪

阶段⑥：退出与后评价

核心痛点：后评价数据手工汇总，财务指标重复测算，缺乏标准化模板，需手工整理结构化表格。
功能点具体要求
退出方案评估支持IPO/转让/回购/清算等多种退出方式的收益测算
后评价自动触发项目退出或达到评价时点后自动推送任务
数据自动抓取从项目全生命周期抓取：决策→实施→运营→财务
财务指标自动测算IRR/NPV/回收期/盈亏平衡点，自动与可研对标
招投标/合同归集固投项目招投标数据、合同数据自动归集分析
跟踪评价首次评价后定期跟踪，自动对比改善/恶化趋势
⭐ 结构化Excel导出自动导出后评价成果Excel，格式严格参照现有模板（模板可定制）

⭐ 后评价结构化Excel导出 — 详细要求

输出格式：.xlsx，两个Sheet：股权投资项目 + 固定资产投资项目，数据由系统自动填充，模板可定制。

股权投资Sheet评价维度：基本情况 → 投资额 → 前期决策 → 实施准备 → 组织实施 → 运营阶段 → 退出情况 → 实施效果 → 协同效益 → 社会效益 → 持续能力 → 主要问题 → 建议 → 跟踪评价

固投Sheet额外维度：土地使用权、招标采购、项目勘察/设计、开工手续、进度/投资/质量/安全/文明施工/竣工验收、技术水平、环境效益

阶段⑦：市值管理配套

核心痛点：市值管理工作碎片化，缺乏系统工具，政策/股东/舆情/ESG数据分散。
子模块核心功能
宏观与监管动态自动收集证监会/交易所/国资委政策，标签体系，关联股价与市值波动，周报/月报/即时推送
股东结构与资本运作前十大股东监测（含股权质押/融资融券），回购/激励/减持线上化，持仓分析模型，窗口期提醒
舆情与危机管理7×24全网监测，NLP情感分析+分级，匹配历史案例，危机全流程：核实→口径→公告→追踪
投资者关系与ESG投资者档案库，业绩说明会/路演/反向路演/开放日线上化，ESG+同业对标，流失风险识别
收并购与投后管理标的数据库（含PE标签），全流程：立项→尽调→交易结构→审批→交割→整合，财务并表+整合计划+里程碑
信息披露与合规内幕知情人登记，信披文件辅助生成（公告/定期报告/临时报告），全流程留痕

阶段⑧：投资制度管理

核心痛点：制度修订后宣贯覆盖不全，各所属公司制度与集团要求的差异难以快速识别。
功能点具体要求
集团制度线上发布发布后自动推送，要求阅读确认，未读超时自动催办
所属公司制度备案上传制度PDF+决策文件→推送投资部备案→归档制度库
⭐ 制度差异智能比对自动提取核心条款，与所属公司制度文本比对，标记差异（严于/弱于/遗漏）
制度汇编自动生成在线版制度汇编，全文检索
制度关联审核审核项目时自动关联适用制度条款

阶段⑨：智能报告生成 ⭐新增模块

核心痛点：投资部日常大量报告撰写（会议纪要、可行性报告、尽调清单、尽调分析），全靠人工，耗时长、格式不统一。

9.1 会议纪要自动生成

功能点具体要求
输入上传会议录音文件（mp3/wav/m4a/ogg等格式）
处理AI语音转文字→智能识别主题/参会人/讨论要点/决议事项/待办任务
输出按固定模板生成结构化会议纪要（Word/PDF）
模板要素会议主题、时间、地点、主持人、参会人、议题清单、决议事项、待办（含责任人+截止时间）
模板可定制支持自定义模板（增删字段、调整格式）
关联项目纪要自动关联项目，归档至项目文件库

9.2 投资可行性分析报告生成

功能点具体要求
输入企业BP（商业计划书）、初步尽调材料、企业基本信息（PDF/Word/PPT）
初版报告AI快速提取BP核心信息，生成《初版投资可行性分析报告》，用于项目初筛
详细版报告结合BP+补充材料+行业数据+财务数据，生成《详细版报告》，用于立项决策
报告维度企业概况、行业分析、商业模式、核心竞争力、财务概况、估值分析、风险提示、投资建议
模板可定制维度可增删、格式可调整、关注重点可配置

初版 vs 详细版差异

维度初版报告详细版报告
数据来源仅BP/初步材料BP+补充材料+行业数据+财务报表
财务分析基于BP数据的初步估算基于财务报表的详细测算（IRR/NPV/回收期）
行业分析基于BP描述的概述结合外部行业数据的深度分析
风险提示常见风险清单基于材料的具体风险识别+应对建议
估值分析粗略估值区间多方法估值（DCF/可比公司/可比交易）
用途项目初筛、内部讨论立项决策、上会材料

9.3 尽调清单自动生成

功能点具体要求
输入企业类型（制造业/科技/地产/金融等）、项目类型、行业特征
输出《尽调材料清单》（Excel/Word），按模块分类（工商/财务/法律/业务/技术/人事）
清单要素序号、材料名称、所属模块、是否必需、说明/要求、提供方、状态（未收/已收/待补）
进度跟踪上传材料后自动更新状态，未收材料自动催办
与尽调衔接材料收集完毕后自动导入智能尽调平台

行业尽调清单模板库（内置，可扩展）

行业额外尽调要点
